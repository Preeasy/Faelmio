FBA一次輸送：混載、入庫ルール、そして見落とされる費用

義烏の工場からAmazonフルフィルメントセンターへ、追加料金なしで段ボールを届ける方法。混載の仕組み、入庫拒否を招く入庫ルール、運賃見積もりには決して載らない費用の全体像を解説します。

工場からAmazonフルフィルメントセンターまでの一次輸送は、利益の出ていた玩具の出品が、静かに損益分岐点ぎりぎりへと変わる工程です。運賃が高いからではありません。一次輸送はサプライチェーンのどの部分よりも意思決定のポイントが多く、判断を誤ればその一つひとつに費用がついてくるからです。

ここでは実務の視点で、混載が実際にどう機能するのか、どのAmazon入庫ルールが入庫拒否を招くのか、そして費用がどこに隠れているのかを見ていきます。

輸送ルートと、そこに関わる人たち#

工場（義烏 / 広東）
  -> エージェント倉庫：混載、品質検査、段ボールの再梱包
  -> 輸出通関（寧波 / 上海 / 深圳）
  -> 海上、航空、または鉄道
  -> 仕向港 + 通関申告
  -> 3PL準備センター（任意）：FNSKU、ポリ袋、外箱ラベル
  -> Amazonフルフィルメントセンター（予約、入庫）

受け渡しのたびに、コストと遅延が生まれる余地があります。パレタイズが雑な工場、予約を落とすフォワーダー、Amazonがすでに受け付けた外箱にラベルを貼り直す準備センター。どれも費目を一つ、そして一週間を追加します。

3つの入庫モデル#

モデル仕組み向いているケース注意点
FCまでのDDPkgまたはCBMあたりの単一価格で、FCの予約日に納品新規セラー、少量、単一SKU単価が最も高い。関税と運賃の内訳が見えなくなる
FOB + 自社フォワーダー + 3PL準備自社で運賃を手配し、関税は輸入時に支払い、準備センターがラベルを貼る月およそ5 CBM以上のセラー事務負担が増える。調整リスクは自社で負う
Amazon提携キャリア / AGLSeller Centralから手配予約をAmazonに任せたいセラー集荷地点の柔軟性が低い。中国での集荷カバレッジが限られる

損益分岐点は数量です。1便あたり数CBMを下回るなら、事務作業の時間を考慮すると通常はDDPのほうが安く済みます。それを超えるなら、運賃と関税を自社で管理するほうが、準備センターの費用を何倍も回収できるだけの節約になるのが一般的です。

混載：それ自体で元が取れる部分#

混載とは、複数の工場、あるいは複数の注文の段ボールを、輸出前に一つの倉庫へ集めることを指します。価値が生まれる理由は三つあります。

  1. 4便ではなく1便で済む。 輸出通関、ISF申告、通関手続き、FC予約は、段ボール単位ではなく便単位の固定費であることがほとんどです。
  2. コンテナ1本まで積み増せる。 少量ではLCLの運賃効率が悪くなります。12 CBMの状態なら、別のサプライヤーが6 CBMを加えるだけでFCLが現実的になります。
  3. 品質検査を一度で、全量に対して行える。 段ボールは中国を出る前に開封・数量確認・パッキングリストとの照合・再梱包が行われます。時間単位で課金する準備センターに着いてからではありません。

実務上のルール：

  • 仕向地とマーケットプレイス単位で混載し、サプライヤー単位では混ぜない。 EUと米国の段ボールを同じ予約に混ぜると、何の利点もなく通関上の問題を招きます。
  • 段ボールの中でSKUを分けられる状態に保つ。 SKU混合のマスターカートンは認められますが、パッキングリストは正確で、外箱には内容物を表示する必要があります。
  • 無料保管は無限の保管ではない。 エージェント倉庫は通常15日間の無料期間を設けており、それを過ぎるとCBM・日単位で保管料がかかります。最後の工場が仕上がる前に船の出港日を計画してください。仕上がってからでは遅いのです。

見積もり前に済ませる外箱の計算#

運賃は課金重量、つまり実重量と容積重量の大きいほうで計算されます。海上LCLでは1 CBMがおよそ1,000 kg、航空では1 CBMが167 kgです。玩具の外箱は通常軽いため、価格を左右するのは容積です。

見積もり依頼を送る前に、やっておく価値のある簡単な計算が二つあります。

  • 1箱あたりのCBM = 縦 × 横 × 高さ（m）
  • 合計CBM = 箱数 × 1箱あたりのCBM
  • 容積重量（航空） = 合計CBM × 167 kg

400箱の外箱が5 cm高すぎるのは、5 cmの問題ではありません。コンテナの積載効率の問題です。外箱の寸法承認は調達の判断であり、梱包の細部ではありません。店頭箱の保護性能と外箱効率のトレードオフについては、梱包コスト比較をご覧ください。

入庫拒否を招くAmazonの入庫ルール#

これらはマーケットプレイスの規則であり、希望事項ではありません。拒否された荷物はゲートで受け取りを断られるか、予定外の準備作業として課金され、段ボールは貴社の負担で返送されます。

外箱の上限（米国、標準）。 1箱あたり最大50 lb（22.7 kg）。ただし、その重量を超える単一商品のみを入れる箱は除きます。どの辺も25 in（63.5 cm）を超えてはいけません。55 lbの玩具の外箱は拒否されます。

Shipment IDラベル。 すべての外箱にAmazonの出荷ラベルが必要で、箱を開けずにスキャンできなければなりません。ラベルは1箱に1枚、継ぎ目には貼らず、テープで覆わないこと。

FNSKUとメーカーバーコード。 Amazonが在庫を混在させる場合、またはFBAの追跡を望む場合は、FNSKUラベルをUPCの上に貼るか、UPCに代えて貼る必要があります。同じ面に両方のバーコードが見えると、スキャンが誤ります。

「セット販売」の表示。 マルチパックやセットは、外側のポリ袋または箱にセットであることを表示し、個別のバーコードを持つ単位に分離できないようにしなければなりません。

ポリ袋のルール。 袋は透明で、窒息警告を表示し、開口部を設けるか、該当サイズの基準を上回る厚みが必要です。玩具ではこれが重要です。店頭箱は工場で袋入れされることが多いからです。

箱内容の情報。 出荷計画で申告した数量は、実際の段ボールと一致しなければなりません。不一致は入庫を遅らせ、調査の引き金になることがあります。

パレット仕様（米国）。 48 × 40 inのGMAパレット、パレット高さを含めて最大72 in、最大1,500 lb、張り出しなし、コーナーボードとストレッチラップを使用します。

バッテリー同梱の出荷。 リチウムを含む玩具にはUN38.3の書類が必要で、破損や膨張したパックを同梱して出荷してはいけません。RC・電子玩具のコンプライアンスをご覧ください。

マーケットプレイスごとに上限は異なり、変更もされます。段ボールを封じる前に、現在の仕様を出荷計画と照らして確認してください。封じた後では遅いのです。

運賃見積もりに含まれない費用の全体像#

費用発生するタイミング回避する方法
入庫配置手数料Amazonが荷物を複数のFCに分割するとき分割を意識的に決める。自分で送る場合のコストと比較する
予定外準備手数料ラベル貼りや袋入れが必要な状態で到着したとき出荷元で正しく準備する。発送前にサンプルを抜き取り検査する
寸法の再測定Cubiscanの測定値が申告より大きいとき商品ではなく、梱包済みの外箱を測る
保管料と長期在庫販売が伸びないときコンテナの最低量ではなく、需要予測に合わせて出荷する
デテンション／ディマレッジコンテナの引き取りや返却が遅れたとき本船到着前にFCの予約を取る
ISFの遅延申告Importer Security Filingの申告が遅い、または誤っているとき船積み24時間前に申告する。違反ごとに課される
カスタムスボンド初回輸入、または単一申告の出荷定期的に輸入するなら継続ボンドに切り替える
関税とMPF/HMFすべての海上輸入運賃見積もりではなく、着地原価に織り込む

手数料の金額はAmazonの料率表が更新されるたびに変わるため、ブログ記事に載った数字は1年も経てば役に立ちません。重要なのは構造です。配置、準備、測定、保管、デテンション、通関手数料。フォワーダーにどれが含まれるか尋ねれば、答えは「どれも含まれません」と返ってくるのが落ちです。

関税と、その数字が動き続ける理由#

玩具の輸入はHS 9503で分類されます。米国、EU、英国はそれぞれ異なる税率を適用しており、2018年以降、米国は中国原産品に追加関税を重ねてきました。第301条リスト、2025年の関税調整、中国原産の貨物に対するde minimisの扱いの変更など、度重なる変更が続いています。

実務上の帰結はこうです。ブログ記事や2023年の表計算ソフトにある関税率を信用してはいけません。 通関ブローカーに、輸入日時点で有効なHTS 9503の該当行と適用される追加関税を確認し、それに基づいて着地原価を組み立ててください。着地原価ガイドでは、計算例を交えて算術を追っています。

まとめ#

  • 混載は仕向地単位で。サプライヤー単位では混ぜない。固定費は便ごとにかかる。
  • 外箱の寸法と重量は生産前に承認する。運賃は容積で決まる。
  • Amazonの入庫ルールは厳格な上限。50 lb、25 in、スキャン可能なラベル、適切なポリ袋。
  • 高くつくのは配置、予定外準備、再測定、保管、デテンションの手数料。どれも運賃見積もりには載らない。
  • 中国製玩具の関税は何度も変わっている。輸入日時点の税率をブローカーと確認する。
  • CPCは通関書類と一緒に保管する。

当社の輸送・物流ページではインコタームズと混載サービスを、品質・コンプライアンスページでは検査と、段ボールとともに移動する書類一式を扱っています。FBAでの販売開始を計画されているなら、SKUリスト、外箱寸法、目標とするFC地域をお送りください。kgあたりの単一の数字ではなく、費目ごとに分解した一次輸送コストをお返しします。
