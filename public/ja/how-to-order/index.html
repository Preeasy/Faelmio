ご注文方法：玩具調達プロセス、支払い、取引条件

プロセス全体の流れ#

ほとんどのバイヤーが問い合わせる前に知りたいのは、2つのことです。どれくらい時間がかかるのか、そして各段階で何を約束するのか。

段階内容標準期間貴社のコミット
1. お問い合わせ製品情報、目標価格、数量、仕向地をお送りいただきます—なし
2. お見積り数量別の単価、MOQ、納期、コンプライアンス範囲を回答します24時間なし
3. サンプリング在庫サンプルの発送、またはカスタムサンプルの開発在庫5〜7日 / カスタム10〜15日サンプル代
4. サンプル承認ご承認、または一致するまで修正します状況によるなし
5. ご注文確定仕様を確定したプロフォーマインボイスの発行1〜2日手付金
6. 生産材料の手配、ラインの計画と稼働通常15〜30日出荷前に残金
7. 検査工程内および出荷前のAQL検査、報告書の送付1〜2日なし
8. 出荷予約、積込、書類、追跡モードによる発送前に残金決済

1. お問い合わせ — お送りいただく内容#

次の5点を早くご提供いただくほど、幅のある回答ではなく実際の数字を早くお伝えできます。

  1. 製品 — 写真、リンク、または現物サンプル
  2. 数量 — 初回注文と年間想定数量
  3. 目標価格 — 概算でも構いません。どの価格帯の工場に当たるべきかの判断材料になります
  4. 仕向地 — 国、Amazonの場合はマーケットプレイス
  5. カスタマイズ — ロゴ、色、包装、またはなし

まだ製品がなくコンセプトだけの場合は、カスタム玩具OEMプロセスをご覧ください。

2. お見積り#

次の内容を含む見積書をお届けします。

  • 複数の数量帯における単価
  • SKU別・色別のMOQ
  • 手付金入金からの生産納期
  • コンプライアンス範囲と試験費用（別途見積り）
  • 包装オプションとそのコストへの影響
  • 着地コストをご希望の場合の運賃概算

私たちは実際に納品できる内容を見積ります。貴社の数量で目標価格が達成できない場合は、その旨をお伝えし、達成するために何が必要かをご説明します。

3. サンプリング#

サンプルの種類内容費用期間
在庫サンプル既存製品をそのまま単価 + 運賃発送まで5〜7日
カスタムサンプル在庫品にロゴや色を反映サンプル代 + セットアップ費10〜15日
開発サンプル新しい金型、新しい成形型、新しい製品金型費用 + サンプル代20〜35日

サンプル代は多くの場合、初回の量産注文に充当されます。前提とせず、見積書に明記します。

4. 成形型と金型の所有権#

これはバイヤーが最も誤解しやすい条項なので、明確に記載します。

  • 金型費用を支払うのは貴社、金型を所有するのも貴社です。 貴社の資金で開発した成形型は貴社に帰属します。
  • 成形型は貴社の生産のため工場で保管されます。ご要望に応じて、移管または文書化された廃棄を手配できます。
  • 貴社の成形型、アートワーク、包装を他の顧客のために再利用することはありません。
  • 貴社がデザインを提供する場合、サンプリング開始前にNDAを締結します。
  • 貴社の製品が第三者の知的財産権を侵害する場合、税関での差押え後ではなく、生産前にご連絡します。

5. 支払い条件#

標準条件

段階割合方法
ご注文確定手付金30%T/T（銀行振込）
出荷前残金70%T/T
少額注文前払い100%T/T、PayPal、またはTrade Assurance

その他の受付方法 — 注文金額と仕向地に応じて、Trade Assurance、PayPal、Western Unionをご利用いただけます。大口注文で条件に合意いただければ、信用状（L/C）も可能です。

支払い条件は各注文のプロフォーマインボイスで確定し、新規顧客、カスタム金型、高額注文では異なる場合があります。貴社がPIを承認するまで、一切の請求は行いません。

6. 生産と進捗報告#

手付金が決済されると、次の流れで進みます。

  • 材料を手配し、ラインを計画します
  • 初品の段階で生産写真をお送りします
  • 承認サンプルからの逸脱があれば、ラインを続行する前に貴社へご相談します
  • 材料不足や工場の生産能力による遅延は、出荷日になってからではなく、直ちに報告します

7. 残金支払い前の検査#

出荷前検査は残金の支払期日に行うため、誰も確認していない貨物に全額を支払うことはありません。

ロットが不合格の場合は、工場負担で手直しのため戻され、再検査します。AQL水準と欠陥クラスの詳細は、品質とコンプライアンスのページをご覧ください。

8. 出荷と書類#

EXW、FOB、DDPからお選びください。発送日に写真付きの積込報告書とコンテナシール番号をお送りし、商業送り状、パッキングリスト、船荷証券を添えます。詳細は輸送とロジスティクスをご覧ください。

キャンセルとクレーム#

状況対応
材料手配前のキャンセル既に発生したサンプリング費用を差し引いて手付金を返金
生産開始後のキャンセル手付金は手配済みの材料と労務に充当し、残額を返金または貨物を出荷
検査での品質不合格工場負担で手直しまたは交換、出荷前に再検査
輸送中の破損積込写真とシール記録に基づく保険請求
誤った商品の出荷当社負担で交換

クレームは写真を添えて書面でご提出ください。2営業日以内に解決案を回答いたします。

お問い合わせを開始する#

よくあるご質問#

最低注文数量はいくつですか？#

製品によって異なります。在庫品は一部のSKUで10 pcsから、カスタム生産は通常500〜1,000 pcsからとなります。各製品ページに個別のMOQを記載しています。

まずサンプルを1点だけ注文できますか？#

はい、お勧めしています。サンプル代は通常、量産注文に充当されます。

新しいAmazonセラーとも取引していますか？#

はい、頻繁にあります。CPC書類、FNSKUラベリング、FBAカートンの準備を対応しており、これは新規セラーが自社で行えない部分です。

Alibabaで見つけた製品を調達できますか？#

はい。その出品の背景にある工場が既に取引のある工場かどうか、また提示価格が非現実的に見えるかどうかもお伝えします。

まだ存在しない製品が必要な場合は？#

それがOEMプロセスです。コンセプト、図面、金型、試作品、承認、生産という流れになります。カスタム玩具OEMをご覧ください。

始める準備はできましたか？

製品写真、サンプル、あるいは目標価格と数量だけでも結構です。24時間以内に、製品・金型・コンプライアンス・運賃を含むコスト付きのご提案をお送りします。
