卵型のクリスピーなスクイーズ・フィジェットトイは、押すと優しく割れるワックスコーティングの外殻と、押すたびに元の形へ戻る耐引裂性PUフォームのコアが組み合わさり、独特の感覚体験を提供します。静かにストレスを解消したい、集中力をサポートしたい子どもや大人、あるいはデスク用の楽しいフィジェットを探している方に最適です。

バイヤーがこのクリスピー・フィジェットトイを選ぶ理由#

  • クリスピーなワックスコーティング — 握るとパリッと弾ける唯一無二の感覚的な質感
  • 耐引裂性PUフォームコア — 押すたびに弾力よく復元し、繰り返し使用に適した設計
  • かわいいキャラクター卵デザイン — 多彩な表情のアソートで、衝動買いやパーティーギフトにぴったり
  • 小売向けカラーボックス — 卵ごとに緩衝フォーム付きで個包装され、スーパーの棚やオンライン出品にすぐ対応
  • 認証済みの安全性 — EN71、ASTM F963、CE、CPCに適合し、世界各地の小売販売に対応

感覚遊びとストレス解消#

クリスピー・フィジェットトイは、不安の緩和、ADHDの集中サポート、感覚遊びに欠かせないアイテムです。95mmの小さなサイズでポケット、筆箱、机の引き出しに収まり、教室、オフィス、旅行、セラピー環境に最適です。

卸売とアソート#

色と表情をアソートした12個セットで販売しています。OEM注文では、1カートン内で色を混在させることが可能です。当社のプッシュポップやスライムのコレクションと組み合わせれば、フィジェットトイのラインナップが完成します。

コンプライアンス#

公認の第三者検査機関（DTI / NBTS）によりEN 71-1/-2/-3およびASTM F963-23に基づく試験を実施済みです。3歳以上に適しています。包装には窒息の危険に関する警告が記載されています。

バイヤーのよくある質問

クリスピー・フィジェットトイは子どもに安全ですか？

+

はい。公認検査機関（DTI / NBTS）によりEN71-1/-2/-3およびASTM F963-23の試験を受けており、CEおよびCPCに準拠しています。小さな部品があるため推奨年齢は3歳以上です。

「クリスピー」な感触はどのようなものですか？

+

外側のワックスコーティングは、押すとパリッと砕ける心地よい質感を与え、耐引裂性PUフォームの内部コアが元の形に戻ります。薄い外皮は繰り返し押すうちに摩耗することがありますが、これは正常で感覚体験の一部です。

最小注文数量はいくらですか？

+

在庫品のMOQは1セット（12個）です。カスタム製品は1,000個、カスタム包装は3,000個からとなります。

どのくらい早く出荷できますか？

+

在庫品は7日以内に出荷します。カスタム注文は15–20日かかります。EXW、FOB、CIF、DDPの条件をご用意しています。

ロゴと包装をカスタマイズできますか？

+

はい。卵へのロゴ印刷またはエンボス加工、完全カスタムのカラーボックス、ハングタグ、FBAラベルに対応しています。ご要望に応じてNDAも締結できます。
