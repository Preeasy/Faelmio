ホラーファンがこのNぬいぐるみを愛する理由#

  • キャラクター忠実なデザイン — シグネチャーの白いマスクフェイス、滴るマスクライン、乱れた黒いスパイキーヘアを細かい刺繍で再現し、Mandela Catalogueの視聴者なら一目でわかる仕上がりです。
  • プレミアム短毛プラッシュ + PP綿 — 高弾性の詰め物がドールの座り姿勢を崩さず保持し、ふわふわで肌触りも優しい。
  • 毛羽に強い密な縫製 — 抱きしめたり、触れたり、長期間棚に飾っても耐えるクリーンな縫い目。
  • 安定した座り姿勢 — 支えなしでデスクや棚に直立して座る設計で、コレクションディスプレイに最適。
  • ホラーファンへのギフトに最適 — 誕生日、ホリデー、ファンミーティングへの間違いのないプレゼント。外見は不気味、中身はソフト。

ドールを売るキャラクターディテール#

Nキャラクターはディテールに宿ります：白いマスクパネルは印刷ではなく刺繍のため、ひび割れたり色褪せたりしません。大きく開いた一つの目とにやりと笑う口は密なサテン刺繍で縫われています。スパイキーヘアには指でスタイリングできる長毛プラッシュを使用。ボディ、腕、足にはより密な短毛プラッシュを使用し、175 gでドールの形状を保ちます。

ディスプレイ用に作られ、抱きしめるために丈夫#

コレクターは棚に映えるドールを求め、ファンはホラーマラソンの間抱きしめても耐えるドールを求めます。高弾性PP綿のコアはその両方を実現 — 握った後も跳ね返り、何ヶ月も座ったシルエットを保ちます。デスクの守り神、棚のオーナメント、撮影小道具、コンベンションのお供として使えます。

バイヤーのよくある質問

このMandela Catalogue N ぬいぐるみのサイズは？

+

高さ250 mm、幅230 mm（25 × 23 cm）で、重さは175 gです — デスクや棚に飾りやすく、ファンミーティングへの持ち運びも簡単な標準的なコレクタブルぬいぐるみサイズです。

ぬいぐるみは安全でお手入れしやすいですか？

+

刺繍ディテール付きのプレミアムプラッシュ生地で作られており、表面の拭き掃除をお勧めします。刺繍のマスクパターンとスパイキーヘアの質感を守るため、浸け置きや洗濯機洗いはしないでください。

このぬいぐるみは何歳から適していますか？

+

3歳以上推奨です。小さな部品による窒息の危険警告があるため、3歳未満のお子様には適していません。

各ドールはどのように梱包されていますか？

+

各ぬいぐるみは個別にポリ袋で密封され、5層輸出カートンに12個入りです。小売対応パッケージ、カスタムカラーボックス、Amazon FBAラベルもご要望に応じて利用可能です。

このぬいぐるみにはどのような認証がありますか？

+

このおもちゃは第三者検査機関（DTI / NBTS）によりEN 71-1/-2/-3およびASTM F963-23に基づいて試験されており、EUおよび米国の輸入コンプライアンス向けにCEおよびCPCの書類が利用可能です。
