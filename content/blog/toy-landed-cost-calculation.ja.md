バイヤーがぬいぐるみ1,000個の見積もりを求めました。工場の回答はFOB寧波でUSD 10.00。バイヤーはUSD 10,000を予算に組みます。ところが実際の到着コストはUSD 14,200で、最初の1個を売る前から製品ライン全体のマージン計算は誤っていました。

これが玩具輸入で最も高くつく計算ミスです。FOBはコストではなく、中国の船上にある商品の価格にすぎないからです。その後のすべての出来事も、あなたのコストです。

実際の着地コストを構成する9項目を、発生する順に挙げます。

## 9つのコスト項目

| # | コスト | 目安 | 見積もり提出者 |
|---|---|---|---|
| 1 | FOBでの商品代 | 基準 | 工場 |
| 2 | 港までの内陸輸送 | 1–2% | 工場 / フォワーダー |
| 3 | 輸出申告・書類 | 0.5–1.5% | 工場 / フォワーダー |
| 4 | 海上または航空運賃 | 8–25% | フォワーダー |
| 5 | 海上保険 | 0.3–0.6% | フォワーダー |
| 6 | 仕向港の港湾費用 | 2–5% | フォワーダー / 通関業者 |
| 7 | 輸入関税 | CIFの0–12% | 税関 |
| 8 | 輸入付加価値税 / 売上税 | 0–27%（還付可能） | 税関 |
| 9 | ラストマイル + FBA入庫 | 3–12% | 3PL / Amazon |

さらに、完全に忘れられがちな2項目を加えます。**1個当たりに按分した試験・認証費用**と、**返品・破損の引当金**です。どちらも実在するコストですが、どの見積もりにも記載されません。

## 計算例：ぬいぐるみ1,000個

FOB寧波でUSD 10.00の1,000個、ロッテルダム向けLCL輸送、EUの輸入者とします。

| 項目 | 金額 | 備考 |
|---|---|---|
| FOB商品代 | USD 10,000 | 1,000 × 10.00 |
| 内陸輸送 + 輸出書類 | USD 280 | 工場から寧波港まで |
| 海上運賃（LCL） | USD 950 | 約4.5 CBM、LCL料率 |
| 海上保険 | USD 45 | CIFの0.4% |
| **CIF価額** | **USD 11,275** | 関税はこの金額に対して計算 |
| 輸入関税（4.7%） | USD 530 | EUの玩具税率、HS 9503 |
| 仕向港 + 通関 | USD 420 | THC、書類、通関業者 |
| 倉庫までのラストマイル | USD 260 | 港から3PLまで |
| **関税込み着地コスト** | **USD 12,485** | 税抜き |
| 輸入付加価値税（21%、還付可能） | USD 2,622 | キャッシュフローでありマージンではない |
| **通関時の支払額** | **USD 15,107** | 口座から出ていく金額 |

つまり1個当たりの着地コストは**USD 12.49**であり、USD 10.00ではありません。25%の開きがあります。付加価値税の課税事業者であれば、この税は還付され、実質コストはUSD 12.49のままです。非課税事業者である場合、またはあなたに代わって付加価値税を徴収するマーケットプレイス経由で販売する場合は、これが実際のコストになるか、60〜90日のキャッシュフロー空白になります。

認証費用の按分も加えます。EN71の試験報告書がUSD 600で、1,000個を発注するなら1個当たりUSD 0.60、FOB価格の6%です。どの見積もりにも表れません。

## 市場別の関税率（HS 9503）

| 市場 | 玩具の一般的な関税 | 備考 |
|---|---|---|
| EU | 4.7% | CIF価額に対して |
| 英国 | 0% | UKグローバル関税 |
| 米国 | 基本0% | **中国製品には追加関税 — 現行税率を確認** |
| 日本 | 0% | ほとんどの玩具が免税 |
| カナダ | 0% | |
| オーストラリア | 0–5% | 号別区分による |
| メキシコ | 5–15% | NOM適合が必要 |

米国の行は強調に値します。2018年から2026年の間に、中国製玩具の関税扱いは通商法301条の措置とその後の調整により何度も変わりました。2021年のブログ記事で読んだ税率が、現在では大きくずれている可能性があります。米国向け注文の価格を決める前に、HTS 9503の現行税率と発動中の追加関税を、ウェブサイトではなく通関業者に確認してください。コンテナ1本でのこの間違いは、5桁の誤差になります。

## 付加価値税と関税は別物

この2つはしばしば混同されます。

- **関税**は実際のコストです。決して戻ってきません。
- **付加価値税 / 売上税**は、課税事業者にとって通過するだけの費用です。輸入時に支払い、申告で還付します。失うのはキャッシュフローと事務負担であり、マージンではありません。

ただし、次のいずれかに当てはまる場合、価格判断に大きく影響します。

- 付加価値税の課税事業者でない（新しいAmazonセラーによくある）
- プラットフォームを供給者とみなすマーケットプレイスで販売している（Amazonが徴収・納付し、あなたは還付できない場合がある）
- 資本が薄い — USD 30,000の出荷に対する付加価値税USD 6,300が数週間拘束される

## 最も高くつく3つの誤り

**1. FOBと競合のDDP価格を比較すること。**
DDP見積もりには運賃、関税、配送が含まれます。これを裸のFOB数値と比べると、DDPサプライヤーは40%高く見えますが、総額では安いことがあります。常に両方を1個当たりの着地コストに揃えてください。

**2. カートンの寸法を忘れること。**
玩具の場合、LCLと航空運賃は重量ではなく容積で決まります。工場が過剰包装したために20%大きくなったぬいぐるみのカートンは、運賃が20%高くつきます。発注確定前にカートン寸法を確認し、充填率が悪ければ異議を唱えてください。カートン設計が包装と運賃の両方にどう影響するかは、[包装コスト比較](/ja/blog/toy-packaging-cost-comparison/)をご覧ください。

**3. 初回出荷の運賃率が通常の率だと思うこと。**
中国〜欧州、中国〜米国の運賃率は、近年では四半期のうちに2〜3倍動きました。30日間有効な見積もりは普通ですが、1年間変わらないと仮定する見積もりは普通ではありません。1個当たりの経済性に運賃の予備費を組み込み、通常は現行見積もりの15〜20%上乗せしてください。

## 再利用できる簡単なテンプレート

```
FOB単価                  = A
カートン当たり個数        = B
カートン数                = C = 総個数 / B
総CBM                     = D
CBM当たり運賃             = E
運賃合計                  = F = D * E
保険                      = G = (A*総個数 + F) * 0.004
CIF価額                   = H = A*総個数 + F + G
関税                      = I = H * 関税率
港湾 + 通関               = J
ラストマイル / FBA入庫    = K
試験費按分                = L = 試験費用 / 総個数
着地コスト合計            = H + I + J + K + L
1個当たり着地コスト       = 上記 / 総個数
着地倍率                  = 1個当たり着地コスト / FOB単価
```

**着地倍率**を追跡してください。中国からEUまたは米国への海上輸送では、中価格帯の玩具でFOBに対して**1.25〜1.45倍**が健全な範囲です。1.6倍を超えると、多くの場合、輸送が非効率です。航空輸送が多すぎる、カートンの充填が悪い、あるいは少量注文でLCLの最低料金を払っているかのいずれかです。1.2倍を下回る場合は、計算に何かが欠けているのが普通です。

## 調達判断が変わる場面

着地コストを正しく計算すると、FOBでは見えなかった3つのことが見えてきます。

- **FOBで5%安くても、カートンが15%かさばる工場は、着地では高くつきます。** 運賃が節約分を食いつぶします。
- **少量注文のLCL最低料金は、1個当たりの経済性を厳しくします。** LCLで300個でも、1,000個と同じ運賃がかかることがあり、1個当たりの運賃は3倍になります。だからこそ[MOQの判断](/ja/blog/lower-moq-toy-factory/)は、実際には運賃の判断なのです。
- **初回注文ではDDPが正解であることがよくあります。** 安いからではなく、そうしなければ雑にしか見積もれない4つのコスト項目を消してくれるからです。

当社の[輸送とロジスティクス](/ja/shipping-logistics/)では、ルート別の輸送日数とインコタームズを掲載しており、カートンデータと仕向倉庫をお知らせいただければ、FOBだけでなく1個当たりの着地コストで見積もります。

## 実践的な次の一歩

直近の3つの見積もりを、上のテンプレートに入れてみてください。着地倍率が1.5倍を超えるなら、問題は通常、工場価格ではなくカートンの容積か輸送方法です。2、3、6、9行目が埋められないなら、それはまさに、手付金を払う前に調達エージェントが提供すべき情報です。

どの見積もりでも、次の5つの数値をサプライヤーに求めてください。提供にコストはかからず、あらゆる比較が誠実になります。

1. FOB単価とMOQ
2. カートン寸法、カートン重量、カートン当たり個数
3. 申告するHSコード
4. 保有する試験報告書とその費用
5. 手付金からカートン完成までのリードタイム
