中国からの玩具発注は、ほぼすべて前払い金で回っています。重要なのは30%を先に払うかどうかではなく、残りの70%がどうなるのか、誰が商品を検品するのか、そして貴社が支払いを拒んだ場合に工場が何をできるのかという点です。

支払い条件は、信頼がゆっくりと築かれる場所であり、一度の取引で失われる場所でもあります。標準的な仕組みが実際にどう機能するのか、そして取引を止めるべき具体的な兆候を以下に示します。

## 提示される五つの方式

| 方式 | 一般的な用途 | リスクを負う側 |
|---|---|---|
| 30%前払い / 70%出荷前 | ほとんどの玩具発注の標準 | 買い手（出荷まで） |
| 30%前払い / 70%検品後 | 経験のある買い手が好む | 分担 |
| 100% T/T前払い | 小口、初回、低額 | 買い手が全額 |
| L/C at sight | USD 50,000–100,000超の発注 | 銀行が仲介 |
| Trade Assurance / エスクロー | Alibabaなどのプラットフォーム | プラットフォーム（部分的） |

**30/70（出荷前）**が既定なのは、工場の資金繰りを守るためです。材料は生産前に購入しなければなりません。買い手の保護は、残金を支払う前の検品から生まれます。ただし、実際に検品するか、検品を代行する人を指名した場合に限られます。

**30/70（検品後）**は、およそUSD 3,000を超える発注で求めるべき方式です。内容は、PO発行時に前払いし、出荷前検品報告書の承認後に残金を解放するというものです。ほとんどの工場はこれを受け入れます。初回取引でこれを拒む工場は、何かを示しています。

**100%前払い**は、数百ドル未満の在庫品やサンプル発注では一般的です。それを超える場合は、長い取引関係がない限り危険信号です。

**L/C at sight**は銀行手数料として0.5–1.5%かかり、正確な書類が求められます。入力ミスが一つあるだけで支払いが数週間遅れることがあります。新しい工場との大口発注には価値があり、小口には不要です。

**Trade Assurance**はプラットフォームが仲介する紛争処理を提供します。初回発注には確かに有用ですが、補償範囲は注文に記録された条件に限られるため、仕様はチャットで合意するのではなく注文書自体に記載しなければなりません。

## 前払い金が実際にカバーするもの

30%は保証金ではありません。次のための運転資金です。

- 前もって購入する生地と付属品
- 金型や版の費用（ある場合）
- 生産ラインに組まれた労働力
- 組み立て前に印刷する包装

前払い金を支払った後にキャンセルすれば、工場はすでにその一部を使っています。だから前払い金は通常返金不可であり、生産途中で注文をキャンセルした場合に未使用材料をどう扱うかを契約に明記すべきなのです。

## 割合よりも重要な条項

仕様が曖昧であれば、支払いの分割は誰も守りません。検収基準をPOに記載してください。

```
1. 前払い：PO署名時に30%、T/T。
2. 残金：買い手が出荷前検品報告書を承認してから5営業日以内に70%
   （AQL II、major 2.5 / minor 4.0）。
3. 検品：第三者または買い手の指名による。工場にて、予定出荷日の7日前。
4. 検品不合格の場合：工場が自己負担で手直しと再検品を行う。
   2回目の検品で不合格なら買い手はキャンセルでき、前払い金は実際に
   消費された材料を差し引いて返金される。
5. 納期遅延：発注額の0.5%/週、上限5%。
6. 双方が署名したゴールデンサンプルを品質基準とする。
```

項目2が行動を変えます。残金が検品結果に依存すれば、工場は運に任せず、上流で品質を管理するようになります。

## 銀行詐欺：誰も警告しないリスク

ビジネスメール詐欺（BEC）は中国調達ではよくある手口で、まさにこの瞬間を狙います。70%を送る前の一週間です。

手口は次のとおりです。
1. 実在の工場と、実在のメールアドレスを使って条件を合意します。
2. 数週間後、ほぼ同一のアドレスからメールが届きます。一文字だけ違う、あるいは表示名は同じでもドメインが`factory.com`ではなく`factory-co.com`になっている、といったものです。内容は、銀行が変わったので残金を新しい口座へ振り込むように、というものです。
3. その口座は香港や深圳の実在口座で、資金は消えます。

**防御は機械的に行うべきで、巧妙さは要りません。**

- 銀行変更は必ず電話で確認してください。以前から持っている番号にかけ、メールに書かれた番号には決してかけないこと。
- 口座名義と契約上の会社名を照合してください。個人名や第三者商社への支払いなど不一致があれば、書面での説明を求める必要があります。
- メールだけで通知された銀行変更は、正しいアドレスからのものでも受け入れてはいけません。音声で確認するまで詐欺として扱ってください。
- 文書化された理由がない限り、前払い金と残金は同じ口座に支払ってください。

買い手がこの手口で残金70%の全額を失う例を私たちは見てきました。調達プロセス全体で最も高くつくミスであり、電話一本で完全に防げるものです。

## 取引を止めるべき危険信号

| 兆候 | 重要な理由 |
|---|---|
| 初回かつUSD 3,000超の発注で100%前払いを主張する | すべてのリスクを買い手に転嫁する |
| 個人口座への振込を要求する | 法的救済がなく、脱税や輸出規制違反の可能性がある |
| 銀行口座情報をメールのみで変更する | 典型的なBEC詐欺の手口 |
| 第三者検品を拒否する | 隠し事があるか、仕様を満たせない |
| 営業許可証や輸出権がない | 合法的に輸出できず、貨物が押収される可能性がある |
| 説明なく市場価格を大きく下回る | 材料の代替が近づいている |
| 暗号資産での支払いを要求する | 追跡できず、紛争処理もない |

最後の二つは、その後の関係がどう進むかを示す兆候でもあります。支払い書類で手を抜く工場は、生地の目付でも手を抜きます。

## 取引を打ち切るべき時

次の場合、交渉ではなく取引を打ち切ってください。

1. **銀行変更が、以前から持っている番号への電話で確認できない。** 例外はありません。
2. **請求書の会社名と受取人が一致しない**、しかも説明が口頭のみである。
3. **検品を拒みながら、積み込み前に残金を求める。** 目隠しでの支払いを求められています。
4. **USD 3,000超の初回発注で100%前払いを要求し**、検品付きの30/70を受け入れない。

いずれの場合も、他の工場は何百もあります。別のサプライヤーを探すコストは一週間です。悪い支払いのコストは、発注全体です。

## 実用的な既定条件

新しい工場との初回発注では、次の条件を設定してください。

```
PO発行時に30%前払い
第三者によるAQL検品後、出荷前に70%
第三者検品の費用：USD 250–350/日（浙江省）
契約に記載された会社へ、電話で確認したうえで支払い
ゴールデンサンプルに双方が署名し、各自保管
POに納期遅延の違約金を明記
```

この仕組みは、評判の良い工場が議論なく受け入れる程度に標準的であり、拒む工場が貴社に知るべきことを示してくれる程度に厳格です。当社の[ご注文方法](/ja/how-to-order/)ページでは、検品が2回不合格になった場合の扱いも含め、すべての発注で用いている版を記載しています。
